# Openisai

Paste a Spotify playlist or album, check the songs, then save them on your phone or export them to Google Drive.

Sarvesh

Spotify is only used to read the track list. The audio comes from YouTube Music, one song at a time, in the best file YouTube serves.

A push to `main` deploys the site and the API to Vercel.
